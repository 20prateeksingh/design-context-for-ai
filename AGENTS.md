# Instructions for AI agents working in this folder

This is a designer's workspace for ONE product. Full behavior spec: **[CLAUDE.md](CLAUDE.md)** (read it if your host loads project instructions; the essentials are inlined below because they break most often on hosts that don't).

1. **Consume the context before designing.** If `design-context/` is empty, capture first: start the dashboard with `node tools/map.js --port 4173` — **in the background**, it's a server that never exits — and let the designer follow its onboarding (or use `skills/capture-product`). `tools/start.sh` is the designer's own double-click path; don't run it yourself, it holds the foreground by design. Dashboard → http://localhost:4173 (captured pages + undownloaded frontier; an empty library shows the onboarding wizard instead). Start at `design-context/registry.json` (machine map: every captured page with route, files, link graph, labeled description — plus additive dashboard fields: per-page `inboundCount`/`clickDepth`, and top-level `identity`, `readiness`, `events`, `offOrigin`). `INDEX.md` is the same content for humans — you don't need it. Each page folder has `page.md` (what it is), `screenshot.png` (how it looks), `page.html` (editable real markup), `content.md` (verbatim copy). **Never invent what the current product looks like — it's captured here.** A page's `label` is a scraped nav string, not an authored title — never quote it as product copy.
2. **Provenance.** Anything marked `method: ai` is model-written orientation prose. Everything else was extracted deterministically from the real product. Never write model-guessed values into `design-context/` — it is captured fact and stays untouched. `annotations.json`'s `hygiene` block (acks + folds) is designer-owned — read it, never write it unasked; `registry.json`'s derived `foldedInto`/`template` fields re-shelve a page under a representative, they never delete it.
3. **Design on copies.** Wireframes go in `wireframes/<page>/round-N/`, built on a COPY of the snapshot. Keep the product's real shell; make new elements visibly lo-fi (gray, dashed, `[placeholder]`-labeled). Never overwrite a round already shown to the designer. For a NEW page/flow with no existing slug, work in `wireframes/new/<concept>/round-N/` — the "Design something new" mode (the dashboard's Use-it tab has the ready prompt).
4. **Capture is read-only.** `tools/capture.js` follows links only — never make it (or any browser you drive) click buttons or submit forms on the designer's product.
5. **Never handle credentials.** Login happens in the browser window `tools/login.js` opens; the designer types their password there. Never ask for or store passwords, cookies, or tokens. `profiles/` never leaves this machine.

If you were pasted this file as a prompt (host without instruction auto-load): follow the five rules above, then read `design-context/registry.json` and ask the designer what they want to work on. If you were started in a folder *above* this one, resolve every path here against the folder holding `tools/` and `design-context/`, not against where you launched.
